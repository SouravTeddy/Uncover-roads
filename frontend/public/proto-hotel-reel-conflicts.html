Multi-city — conflict scenarios

Edge cases where the simple "hotel row" logic breaks. Each scenario shows what the card should display and why.

Conflict 1 — Arrival day, before hotel check-in
User arrives Mumbai at 10 AM. Hotel check-in is 3 PM. First stop is at 11 AM — they haven't checked in yet. Hotel is 35 min from the airport.

Before check-in: airport is the anchor, shown in blue.
After check-in: hotel takes over as anchor, shown in gold.
Rule: If stop time < check-in time → anchor = arrival terminal. If stop time ≥ check-in time → anchor = hotel. If no check-in time set → default to 2 PM.
