Pin Detection: OSRM as Ground Truth

Distance was wrong. The routing engine already knows about water. Here's the corrected design — and most of it is already built.

What's already in the codebase

Already built — just not wired to pin-add yet

routeInterCity(lat1,lon1,lat2,lon2) calls OSRM backend. Returns null when there is no road route — which is exactly what happens for any ocean, strait, or island crossing. No extra API. No special water detection. OSRM itself encodes the physical world.

detectTransitMode() wraps this: null → flight, > 480min road → flight, > 120min road → train, else → drive. Already handles every case correctly.

Both are used in buildJourneyLegs() today. The only gap: they run after cities are grouped. We need to run them during pin add to stamp the right _city.

Detection flow on every pin add
1

Fast path: within 30km of a known city centroid sync · instant

Compute haversine from new pin to centroid of each known city. If within 30km → same city, assign that _city. Done. No API call. 30km is small enough that false positives (wrong city) are essentially impossible — most cities are tighter than this.

2

Slow path: > 30km from all known centroids → reverse geocode async

Call Nominatim reverse geocode on the pin's lat/lon to get city name. If city name matches a known city → assign it (user is in the outskirts). If new city name → proceed to step 3.

3

New city confirmed → OSRM check async

Run detectTransitMode() between the nearest existing city centroid and the new pin. OSRM returns null → water/barrier → flight (or ferry if < 200km). OSRM returns a route → drive or train based on duration. This is the ground truth — no distance heuristic involved.

4

Stamp + notify

Stamp _city on the pin. Fire ADD_CITY_FOOTPRINT dispatch. Show non-blocking toast with city name + detected transit mode. Footprint chip appears. Done.

Decision tree (step 3 expanded)
🗺️
OSRM road route exists? Call routeInterCity() between city centroids
🚗
Road exists · < 2h drive → nearby city, same-day reachable. Transit card: "Drive · 45 min"
🚄
Road exists · 2–8h drive → train/bus city hop. Transit card: "Train · 2h 30min". CityHopOverlay fires.
✈️
Road exists · > 8h → road technically exists but impractical. Classify as flight.
⛴️
No road route · haversine < 200km → water crossing but nearby. Ferry. "Ferry · ~3h" (estimated from distance).
✈️
No road route · haversine > 200km → ocean crossing. Flight. "Flight from Tokyo ✈️"
