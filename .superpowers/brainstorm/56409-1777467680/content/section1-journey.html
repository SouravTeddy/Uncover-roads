Phase 3 — Persona Reveal
Your Traveler Identity
Full-screen moment. Mood image + archetype identity + story headline + trait chips. Two CTAs: primary "See your map →", secondary "↺ Retake questions".
PersonaScreen

4
Phase 4 — Explore
Destination → Map
User picks city + date range (single calendar). One-tap discovery mode toggle per city. Map opens with three pin layers live. This is the core product loop.
DestinationScreen MapScreen
Three pin layers: Famous (gold/star) · Reference ghost (muted purple) · User-added (blue)
Four pin states: normal → saved ❤️ → added to itinerary (ring) → saved + added
"Surprise Me" CTA → full multi-day itinerary, straight to itinerary view
Discovery mode: [ Essentials ] [ Local's pick ] — one tap per city
Pin tap → 40% card slides up (expandable to full)
Card: hero image · name · rating · why this for you · 2 intel pills · local tip
Card CTAs: Save (❤️) · Add to itinerary · Similar ·
Famous pins: Google Places seeded + hand-curated for Tier 1 cities
Reference pins: engine-generated per persona + city on destination select
Path A — Self-build
User taps pins, adds places, hits "Build itinerary" when ready. Engine runs all 5 layers.
Path B — Surprise Me
Engine builds full N-day itinerary from broader Google Places pool. Straight to itinerary view. Fully editable.
5
Phase 5 — Itinerary
Read-Only Output · Edit via Map
Itinerary is the engine's output — never the editing surface. User views their day-by-day plan. Every engine decision has a WHAT+WHY+CONSEQUENCE message. One exception: swipe-to-remove on a stop triggers rebuild.
RouteScreen (rebuilt) ItineraryView (1325 lines — deleted) ItineraryCards (1016 lines — deleted) ItineraryDayView ItineraryStopCard EngineMessageBanner
Read-only. No inline editing except swipe-to-remove
Swipe-to-remove → confirm → engine rebuilds → counts as 1 generation
"Edit trip" → map opens with pin snapshot → user edits → "Rebuild" → new generation
Each rebuild = new saved itinerary entry. Old one preserved.
Generation counter shown · paywall at threshold
Engine messages: dismissable banners showing WHAT + WHY + CONSEQUENCE
AI-generated text marked with ✦ indicator
Factual data (hours, ratings, prices) sourced from Google Places only
6
Phase 6 — Persistence
Saved Trips · Profile · Saved Places
Bottom nav: Explore · Itinerary · Saved Places · Profile. Saved Places is separate from itinerary — places the user bookmarked for later reference. Profile allows persona retake.
TripsScreen SavedPlacesScreen ProfileScreen
Saved places (❤️) = bookmarks, separate from itinerary additions
Saved places screen: list view, tap to see on map, add to next trip
Profile: persona retake · dietary prefs · units · notification settings
Trips: history of all generated itineraries, preserved forever
